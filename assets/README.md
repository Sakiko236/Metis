# Metis Assets 🎨

The `assets/` directory contains visual design assets, logos, and UI preview materials for Metis.

---

## 📁 File Overview

| File | Description |
| :--- | :--- |
| [`metis-icon.png`](metis-icon.png) | High-resolution application brand icon used in documentation, headers, and marketplace listings. |
| [`firstpage.png`](firstpage.png) | High-definition screenshot demonstrating the minimalist desktop interface, active file whitelist, and conversational workspace. |
| [`metis_kawaii_m_studio.html`](metis_kawaii_m_studio.html) | Interactive browser-based SVG design studio used to prototype mascot moods (happy, wink, love, focused, sleepy), color palettes, and SVG vector paths. |
